### GYAKORLÓ HÁZI FELADAT

A korábbi házi feladatban készített saját statikus oldalak kiegészítése CSS-el. A cél az, hogy alapvető CSS beállításokat tudjatok megvalósítani.

1. a korábbi feladathoz hozzatok létre egy styles.css fő állományt, amiben pár alapvető CSS beállítást végezzetek el
2. az egyes aloldalakhoz hozzatok létre saját CSS-t, ami csak arra az oldalra vonatkozó szükséges "plusz beállításokat" tartalmazza
3. media query segítségével legalább 1 oldalon (pl. index.html) valamilyen változást alakítsatok ki mobile-tablet-desktop hármasra vonatkozóan
4. a kontakt form gombjára egy tetszőleges stílust adjatok meg (ehhez button css generator használható)
